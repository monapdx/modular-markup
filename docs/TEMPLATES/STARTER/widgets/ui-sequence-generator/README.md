# UI Sequence Generator

A tiny Modular Markup-style frontend tool for quickly formatting software navigation and interaction sequences.

## How to use

1. Type a normal sequence with `>` between navigation steps, for example:
   `Windows Explorer > View > Group by > Type`
2. Click one of the interaction icons above the editor to insert it at the current cursor position.
3. Copy the plain-text sequence, copy the generated HTML, or download a standalone HTML file.

The first text item is automatically treated as the software program and given distinct styling.
